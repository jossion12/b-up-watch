# UP雷达 · 前后端启动说明

本文档说明如何本地启动 **UP雷达** 的前端和后端服务。

---

## 一、环境要求

| 服务 | 依赖 |
|------|------|
| 后端 | Python >= 3.10 |
| 前端 | Node.js 20+ |

建议额外安装：

- `ffmpeg` / `ffprobe`：字幕本地 ASR 兜底时需要用到的音视频工具。
- `git`：拉取和更新代码。

---

## 二、项目结构

```
b-up-watch/
├── backend/       # FastAPI + SQLite 后端
├── frontend/app/  # React + Vite + Tailwind CSS 前端
└── docs/          # 项目文档
```

---

## 三、后端启动

后端位于 `backend` 目录，基于 FastAPI 构建，数据库使用 SQLite。

### 1. 进入后端目录

```bash
cd backend
```

### 2. 创建并激活 Python 虚拟环境

Windows：

```bash
python -m venv .venv
.venv\Scripts\activate
```

macOS / Linux：

```bash
python -m venv .venv
source .venv/bin/activate
```

### 3. 安装依赖

```bash
pip install -e ".[dev]"
```

如果希望启用 ASR 本地推理能力，可额外安装 ASR 依赖：

```bash
pip install -e ".[asr]"
```

### 4. 配置环境变量

复制示例配置文件：

```bash
cp .env.example .env
```

然后按需编辑 `.env` 中的关键配置：

| 配置项 | 说明 |
|--------|------|
| `BILIBILI_SESSDATA` | B 站登录 Cookie；留空也能跑，但搜索/字幕更容易触发风控。启动后也可在 Web 页面右上角「设置」中配置 |
| `QWEN_ASR_MODEL_PATH` | 本地 Qwen3-ASR 模型路径，用于字幕兜底转写；留空则关闭本地 ASR |
| `QWEN_ASR_DEVICE` | ASR 推理设备，如 `cuda:0` 或 `cpu` |
| `DATABASE_URL` | SQLite 数据库地址，默认 `sqlite:///./data/upwatch.db` |

### 5. 启动服务

```bash
uvicorn app.main:app --reload
```

默认监听：

- 后端地址：`http://127.0.0.1:8000`
- OpenAPI 文档：`http://127.0.0.1:8000/docs`

首次启动时，SQLite 数据库会自动创建在 `backend/data/upwatch.db`。

### 6. 运行测试（可选）

```bash
pytest
```

## 四、前端启动

前端位于 `frontend/app` 目录，基于 React + Vite 构建。

### 1. 进入前端目录

```bash
cd frontend/app
```

### 2. 安装依赖

如果尚未安装依赖，执行：

```bash
npm install
```

### 3. 启动开发服务器

```bash
npm run dev
```

默认监听：`http://localhost:5173`

### 4. 构建生产版本（可选）

```bash
npm run build
```

构建产物输出在 `frontend/app/dist` 目录。

### 5. 预览生产构建（可选）

```bash
npm run preview
```

---

## 五、完整启动顺序

建议按以下顺序启动服务：

```bash
# 1. 启动后端（端口 8000）
cd backend
.venv\Scripts\activate
uvicorn app.main:app --reload

# 2. 在另一个终端启动前端（端口 5173）
cd frontend/app
npm run dev
```

然后访问 `http://localhost:5173` 使用前端页面。

## 六、常见问题

1. **前端无法访问后端接口**
   - 确认后端是否已启动，且前端配置的 API 地址正确。
   - 检查是否存在跨域问题；后端已默认处理 CORS，但可查看 `app/main.py` 配置。

2. **B 站接口返回 `-352` / `-412` 风控**
   - 说明当前请求缺少有效登录态或 wbi 签名过期。
   - 在 Web 页面右上角「设置」中配置有效的 `BILIBILI_SESSDATA`，保存后即时生效；或在 `.env` 中配置后重启后端。

3. **字幕接口返回 `SUBTITLE_UNAVAILABLE`**
   - 该视频没有 UP 主上传字幕，且 B 站 AI 字幕也不可用。
   - 如需本地 ASR 兜底，配置 `QWEN_ASR_MODEL_PATH` 并安装 ASR 依赖。

4. **本地 ASR 无法使用**
   - 确认 `ffmpeg` / `ffprobe` 在系统 PATH 中可调用。
   - 确认 `qwen_asr` 包与 Qwen3-ASR-1.7B 模型已正确安装和配置。
